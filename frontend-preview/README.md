# RedPit — Responsive Creator Studio Frontend

This package contains the RedPit dark-and-red responsive onboarding experience.

## Preview locally
Open `index.html` in a modern browser. Keep the `assets` folder beside it so the hero artwork loads.

## Publish on Render
For this frontend-only preview, create a **Static Site** on Render:
- Build command: leave blank
- Publish directory: `.`
- No start command

If you later add the authenticated backend, video rendering, persistent database, AI services, or real social publishing, deploy the combined application as a **Web Service** instead.

## Important functionality note
This is a polished interactive frontend prototype. The setup selections and wizard navigation work in the browser. Voice previews, AI video generation, account OAuth connections, automated publishing, and scheduled background jobs are not live integrations in this package. Those require backend services, platform developer applications/OAuth approval, secure token storage, a persistent database, and a worker/scheduler.

## Brand
RedPit is an original brand identity using a dark charcoal interface with vivid red accents.
